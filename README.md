# Мои ежемесячные расходы: онлайн-версия с автообновлением

Приложение лежит на вашем сайте (бесплатный хостинг GitHub Pages). Каждый день специальный скрипт заходит на официальную страницу Республиканской службы по тарифам Бурятии, и если тарифы Улан-Удэ изменились, обновляет файл `data.json`. Приложение при каждом открытии берёт свежий `data.json`, пересчитывает ЖКУ и показывает разницу между прежними и новыми тарифами.
Ваши суммы, зарплаты и расходы хранятся только в вашем браузере или на телефоне и на сайт не отправляются.

## Что обновляется само, а что вручную

| Что | Как обновляется |
|---|---|
| Тарифы ЖКУ Улан-Удэ (вода, водоотведение, горячая вода, отопление, электроэнергия, ТКО) и даты периодов | Само, ежедневно, с сайта РСТ Бурятии |
| Размеры выплат и пороги: прожиточные минимумы, материнский капитал, выплата на первого ребёнка, лимиты вычетов, текст про индекс | Вручную в `data.json`, раздел `constants` и `notice`. Обычно меняется раз в год: в январе прожиточные минимумы, в феврале материнский капитал |
| Условия льготных программ (текст карточек на вкладке «Льготы») | Вручную в `index.html` |

В приложении под заголовком всегда видно, откуда данные и от какого числа. Если размеры выплат не проверялись больше 120 дней, на вкладке «Льготы» появится предупреждение. После проверки поменяйте дату `reviewed` в `data.json`.
Если вы сами исправили тариф в приложении, автообновление для этой цифры отключается. Кнопка «Сбросить мои правки» возвращает данные РСТ.

## Запуск за 10 минут

1. Зарегистрируйтесь на github.com и создайте новый репозиторий, например `raskhody`. Для бесплатных Pages репозиторий должен быть публичным. В нём не будет ничего личного.
2. Загрузите в него все файлы из этой папки вместе со скрытой папкой `.github`. Проще всего командами в терминале внутри папки:

```
git init -b main
git add .
git commit -m "Первая версия"
git remote add origin https://github.com/ВАШ-ЛОГИН/raskhody.git
git push -u origin main
```

Через веб-интерфейс тоже можно: «Add file», «Upload files», но папку `.github` на Mac придётся сначала показать клавишами Cmd+Shift+точка.

3. В репозитории откройте Settings, затем Pages, в поле Source выберите «GitHub Actions».
4. Откройте вкладку Actions, выберите «Обновление тарифов и публикация сайта» и нажмите «Run workflow».
5. Через минуту-две сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/raskhody/`. Дальше всё работает само, обновление идёт каждый день около 11:17 по Улан-Удэ.

## Как пользоваться на устройствах

- **iPhone:** откройте адрес в Safari, «Поделиться», «На экран „Домой“».
- **Android:** откройте адрес в Chrome, меню, «Установить приложение».
- **Windows и Mac:** откройте адрес в Chrome или Edge и нажмите значок установки в адресной строке («Установить»). Приложение появится как обычная программа со своим окном и значком.

Без интернета открывается последняя сохранённая копия, данные в ней помечаются предупреждением.

## Если нужен именно файл .exe или .dmg

Файл `.exe` открывает то же приложение, но данные ему нужно откуда-то брать: впишите адрес вашего сайта в `index.html` в строку `var REMOTE='';`, например `var REMOTE='https://ВАШ-ЛОГИН.github.io/raskhody/data.json';`. Затем установите Node.js (версия LTS) и выполните в папке:

```
npm install
npm run build:win     # Windows, в папке dist появится .exe
npm run build:mac     # macOS, делать на Mac, в папке dist появится .dmg
```

Для обычной работы установка из браузера (пункт выше) проще и тоже обновляется сама, а `.exe` нужно пересобирать только при изменении самого приложения, тарифы он подтягивает из сети.

## Если автообновление тарифов перестало работать

Запуск в разделе Actions станет красным, а GitHub пришлёт письмо. Сайт при этом продолжает работать на прежних данных. Возможные причины и что делать:

- Сайт РСТ изменил вёрстку. Скрипт `scripts/update_tariffs.py` в этом случае ничего не меняет и сообщает причину в журнале запуска. Тарифы можно поправить вручную: откройте `data.json` на GitHub (значок карандаша), впишите новые значения, `updated` и при необходимости `periods`, сохраните. Сайт обновится сам.
- Сайт РСТ не открывается с зарубежных серверов GitHub. Тогда запускайте скрипт у себя по расписанию, например на домашнем NAS или компьютере: `python scripts/update_tariffs.py`, затем `git add data.json`, `git commit`, `git push`. Проверить скрипт без изменений можно командой `python scripts/update_tariffs.py --dry-run`.

Важно: я не смог проверить скрипт на настоящей странице РСТ, мои инструменты к ней доступа не имеют. Он проверен на образце `scripts/sample_tariffs.html`, который собран по тексту этой страницы. Поэтому первый запуск в Actions посмотрите внимательно: в журнале должна появиться строка «Тарифы не изменились» или список изменений. Если там ошибка, пришлите её текст, и я поправлю скрипт.

## Проверка вручную

```
python scripts/update_tariffs.py --file scripts/sample_tariffs.html --dry-run
```

## Вкладки по месяцам

Над показателями расположена полоса месяцев, начиная с месяца первого запуска (для вас это октябрь 2026). Оранжевая точка отмечает текущий месяц, зелёная показывает, что месяц уже заполнялся. Кнопка «+» добавляет следующий месяц.

- В каждом месяце свои доходы, расходы, показания воды, электроэнергии и отопления.
- Новый месяц открывается с данными предыдущего, вам остаётся поправить отличия. Кнопка «Заполнить как в прошлом месяце» возвращает эти значения.
- На вкладке «ЖКУ и тарифы» есть поле «ЖКУ по квитанции»: если ввести сумму, она заменит расчёт в этом месяце.
- Тарифы по умолчанию выбираются по месяцу автоматически: до октября 2026 старые, с октября новые. Для месяцев после 2026 года используются последние действующие тарифы, пока РСТ не опубликует новые.
- Вкладка «Итоги по месяцам» собирает все заполненные месяцы: доход, расходы, ЖКУ, остаток и остаток нарастающим итогом.

Данные месяцев хранятся в браузере каждого устройства и между телефоном и компьютером не синхронизируются.

## Счётчик сумм и рабочие обеды

У каждой категории на вкладке «Бюджет» есть кнопка «＋». Она открывает счётчик: вносите траты из банка по одной суммой и нажимайте «Добавить» (или Enter). Можно ввести и выражение, например `99+101`. Сумма категории считается сама, а на кнопке показано количество записей. Ошибочную сумму убирает «×», все записи сразу убирает «Очистить». Пока записи есть, поле суммы заблокировано.

Добавлена категория «Рабочие обеды» (по умолчанию 5 000 ₽ в месяц как пример). Записи счётчика относятся к своему месяцу и в следующий месяц не переносятся, переносится только итоговая сумма.

## Загрузка банковской выписки

В октябрь 2026 один раз загружена выписка за 01–14.10.2026: 69 операций разложены по категориям, каждая лежит в счётчике «＋» своей категории. Добавлены категории «Кафе, кофе, шаурма», «Подписки и цифровой контент», «Табак», «Дом и ремонт», «Переводы людям», «Комиссии банка» и поступления «Пополнения наличными и прочие». Переводы между своими счетами в расходы не входят.

## Сохранение и перенос между устройствами

В каждой вкладке сверху есть кнопка «Сохранить изменения» и строка состояния. Данные и так сохраняются на устройстве после каждой правки. Эта версия (сайт или программа) хранит их только на вашем устройстве. Чтобы перенести данные на другое устройство, нажмите «Скачать копию», отправьте файл себе и на другом устройстве нажмите «Загрузить копию». Автоматическая синхронизация между устройствами работает в версии на странице Claude, где данные хранятся в вашем аккаунте.

## Новое: выписка, платежи, до зарплаты, маркетплейсы, жена, фото чека

- **Выписка из банка.** На вкладке «Бюджет» кнопка «Выписка из банка (CSV)». Приложение читает выписку ВТБ, раскладывает операции по категориям, показывает список на проверку, и вы снимаете лишние отметки или меняете категорию. Исправления запоминаются как правила для следующих выписок. Уже внесённые операции пропускаются, поэтому один и тот же файл можно загружать повторно.
- **Платежи.** Вкладка «Платежи»: ипотека или аренда, кредиты, детский сад, ЖКУ, связь. Дату оплаты вы ставите сами, сумма берётся из категории бюджета и переходит в следующие месяцы. Отметка «оплачено» у каждого месяца своя.
- **На день до зарплаты.** Укажите дни аванса и зарплаты и сколько сейчас на счетах. Из денег вычитаются неоплаченные платежи до ближайшей выплаты, остаток делится на число дней.
- **Доходы.** Добавлены «Отпускные» и «Материальная помощь» отдельными строками, у каждой есть счётчик сумм.
- **Нерегулярные расходы.** Категория «Нерегулярные: ОСАГО, ТО, отпуск, налоги, подарки».
- **Маркетплейсы и «Расходы жены».** Отдельные вкладки с тем же счётчиком сумм, итоги попадают в бюджет.
- **Фото чека и квитанции** работает на странице Claude (нужен вход в аккаунт). В пакете для сайта и программы этой кнопки нет.
- **Одновременная правка.** Если на двух устройствах правки сделаны одновременно, они объединяются, а не затирают друг друга.

## Свои категории

Вкладка «Маркетплейсы» теперь блок на вкладке «Бюджет» под расходами. Под каждым списком (расходы, маркетплейсы, расходы жены, доходы) есть строка «Добавить категорию». У каждой категории справа кнопка ×: нажмите её, затем «Удалить?» для подтверждения. Встроенные категории не стираются, а скрываются, их можно вернуть ссылкой «вернуть …» под списком. Удалённая категория исчезает из расчётов всех месяцев.

## Инструменты месяца и диаграммы
- «Обнулить месяц» (вкладка «Бюджет», над расходами): ставит в 0 все суммы выбранного месяца, очищает счётчики и отметки оплаты. Нужно подтвердить вторым нажатием. Расход воды и электричества не трогается. ЖКУ без квитанции считается по тарифам.
- «Всё как в прошлом месяце»: переносит суммы всех категорий.
- «↶» у каждой категории и у каждого дохода: берёт сумму и список платежей этой категории из прошлого месяца.
- «Куда уходят деньги»: две круговые диаграммы выбранного месяца, расходы и доходы.
